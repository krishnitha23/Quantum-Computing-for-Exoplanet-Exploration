# Quantum Computing for Exoplanet Exploration 🚀

## About the Project
This beginner research prototype explores how quantum computing concepts could be applied to exoplanet exploration using real astronomical observations from NASA's TESS mission.

## What This Project Does
- Retrieves stellar brightness data using Lightkurve.
- Visualizes and analyzes brightness variations.
- Searches for potential transit-like signals.
- Demonstrates a Grover-style quantum search circuit using Qiskit.
- Discusses the limitations of applying quantum computing to astronomical data analysis.

## Technologies Used
- Python
- NASA TESS data
- Lightkurve
- NumPy and Matplotlib
- Qiskit and Qiskit Aer

## Future Improvements
- Validate candidate signals using established astronomical methods.
- Compare classical and quantum-inspired search approaches.
- Explore how quantum algorithms might support future astronomical data analysis.

**Goal:** Explore the intersection of quantum computing and space science.
